# CodeAlpha_MusicPlayer
# 🎵 Music Player Website

## 📌 Overview
A modern and responsive music player built using HTML, CSS, and JavaScript. It supports playing multiple songs with an attractive user interface and smooth controls.

## ✨ Features
- Play/Pause music
- Next & Previous song
- Progress bar
- Album cover display
- Responsive design
- Modern UI
- Supports 12 songs (English & Hindi)

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
